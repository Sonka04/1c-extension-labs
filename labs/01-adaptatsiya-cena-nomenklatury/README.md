# 01. Адаптация: автоподстановка цены номенклатуры

Расширение типа «Адаптация» для документа «Заказ клиента»: при выборе номенклатуры в табличной части автоматически подставляется цена из справочника «Номенклатура» (реквизит `А1_Цена`).

Ключевой код: [`Document/ЗаказКлиента/DocumentForm/ФормаДокумента/DocumentForm.obj.bsl`](Document/ЗаказКлиента/DocumentForm/ФормаДокумента/DocumentForm.obj.bsl) — обработчик `ПриИзмененииПосле` на клиенте вызывает серверную функцию, которая делает запрос к справочнику.
