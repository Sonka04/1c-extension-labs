# 03. Перехват метода через аннотации &Перед / &После

Демонстрация трёх вариантов перехвата стандартного обработчика формы `ПриСозданииНаСервере` справочника «Сотрудники»: базовая версия, версия с аннотацией `&Перед` и версия с `&После`, каждая по-своему модифицирует список выбора должностей в выпадающем списке.

Ключевой код: [`Catalog/Сотрудники/CatalogForm/ФормаЭлемента/CatalogForm.obj.bsl`](Catalog/Сотрудники/CatalogForm/ФормаЭлемента/CatalogForm.obj.bsl).
