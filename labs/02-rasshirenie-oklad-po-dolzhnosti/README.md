# 02. Расчёт оклада по должности

Расширение справочника «Сотрудники»: при выборе должности реквизит «Оклад» автоматически заполняется минимальным окладом, заданным в справочнике «Должности».

Ключевой код: [`Catalog/Сотрудники/CatalogForm/ФормаЭлемента/CatalogForm.obj.bsl`](Catalog/Сотрудники/CatalogForm/ФормаЭлемента/CatalogForm.obj.bsl).
