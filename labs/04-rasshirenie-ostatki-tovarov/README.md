# 04. Остатки товаров по регистру накопления

Расширение с документами «ПоступлениеТовара» / «ПродажаТовара» и регистром накопления «ОстаткиТоваров». В форме элемента справочника «Товары» — запрос к виртуальной таблице остатков регистра и предупреждение в форме, если остаток товара меньше 3 единиц.

Ключевой код: [`Catalog/Товары/CatalogForm/ФормаЭлемента/CatalogForm.obj.bsl`](Catalog/Товары/CatalogForm/ФормаЭлемента/CatalogForm.obj.bsl).
