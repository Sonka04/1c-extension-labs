# Лабораторные работы: механизм расширений конфигурации 1С

Серия учебных мини-расширений на платформе **1С:Предприятие 8.3**, в которых последовательно отрабатывается механизм расширений конфигурации — от простого добавления функционала до перехвата стандартных методов через аннотации `&Перед`, `&После`, `&Вместо`.

Это подготовительный этап перед [рабочим проектом для ООО «СДВ ЭКСПО»](https://github.com/Sonka04/sdv-expo-1c-archive-cennik) — та же техника (аннотации, интерактивные обработчики форм, запросы к регистрам) применена там уже на прикладной боевой задаче на основном месте работы.

## Лабораторные работы

| № | Расширение | Что отрабатывается |
|---|---|---|
| 01 | [adaptatsiya-cena-nomenklatury](labs/01-adaptatsiya-cena-nomenklatury) | Расширение типа «Адаптация»: автоподстановка цены номенклатуры в документ «Заказ клиента» при выборе товара |
| 02 | [rasshirenie-oklad-po-dolzhnosti](labs/02-rasshirenie-oklad-po-dolzhnosti) | Расчёт оклада сотрудника через запрос к справочнику «Должности» при изменении реквизита формы |
| 03 | [rasshirenie-perehvat-do-posle](labs/03-rasshirenie-perehvat-do-posle) | Перехват стандартного события формы `ПриСозданииНаСервере` через аннотации `&Перед` / `&После` — динамическое изменение списка выбора |
| 04 | [rasshirenie-ostatki-tovarov](labs/04-rasshirenie-ostatki-tovarov) | Запрос к виртуальной таблице остатков регистра накопления, вывод предупреждения в форме при низком остатке товара |

## Стек

1С:Предприятие 8.3 · BSL · механизм расширений конфигурации · аннотации `&Перед`/`&После`/`&Вместо` · запросы к регистрам накопления.

Исходники выгружены из бинарных файлов `.cfe` инструментом [v8unpack](https://github.com/saby-integration/v8unpack), без использования технологической платформы 1С.
